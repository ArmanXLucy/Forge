### 3.2 Phase 4 aggregation tests (`tests/ai-monitoring.test.ts`, 7)

| Test | What it proves |
| --- | --- |
| Unknown ratios are null, not zero | Empty windows render `—`, not `0%` |
| Recommendations, failures and latency counted separately | Success is not inflated by unrelated events; p95 uses only measured runs |
