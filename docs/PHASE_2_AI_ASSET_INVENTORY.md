### Version pinning

- ORT versions are exact constants in source and protected by tests.
- MediaPipe Tasks Vision is an exact version.
- The pose model uses `/latest/` and is **not immutable**. This is the main supply-chain/reproducibility gap.
- No SRI is used because these are dynamic ESM/WASM imports. Do not add SRI unless the runtime supports it without breaking.

### No duplicate local ORT WASM

Before Phase 2, Vite emitted an unused 14.8 MB `ort-wasm-simd-threaded-*.wasm` into `dist/assets`. A Vite resolve condition now selects ONNX Runtime's external-WASM export. The CDN remains the configured WASM source, and runtime verification passed. This removed 14.8 MB from the deployment without changing inference.

## 4. AI contracts protected by tests

- Recommendation schema has exactly 24 target labels.
- Numeric inputs: `Age`, `Weight_kg`, `Height_cm`, `BMI`.
- Categorical inputs: `Gender`, `Goal`, `Equipment`, `Experience`, `Injury`.
- ONNX inputs: 9; outputs: 2 (`label`, `probabilities`).
- Form feature order: exactly 60.
- Form class order: `BAD`, `GOOD`.
- Thresholds: squat 0.66, bicep curl 0.64, push-up 0.58.
- Public recommendation files match the validated artifacts byte-for-byte.

Any intentional model update must update the hashes/sizes in the verifier and tests after review. Do not bypass the verifier.
